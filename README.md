# Kushagra Awasthi — Portfolio

Personal developer portfolio featuring a 240-frame interactive canvas background, cinematic preloader, and project case studies.

🌐 **Live Demo:** [https://kushagraportfolioo.netlify.app/](https://kushagraportfolioo.netlify.app/)

---

## ⚡ Tech Stack

- **Frontend:** Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Canvas Rendering:** High-performance scroll-driven WebP frame sequence
- **Design:** Modern glassmorphism, responsive typography, custom design system

---

## 📂 Project Structure

```text
├── index.html       # Main HTML markup
├── style.css        # Core styling, responsive layouts & animations
├── script.js        # Canvas scrubbing & interactivity
├── img/             # High-res and mobile-optimized frame sequences
│   ├── lg/          # Desktop frames
│   ├── sm/          # Mobile frames
│   └── projects/    # Project case study previews
└── server.js        # Lightweight local development server
```

---

## 💻 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/kushagraawasthi37/portfolio.git
   ```
2. Run the local dev server:
   ```bash
   node server.js
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.
